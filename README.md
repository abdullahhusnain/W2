Network Footprinting & Network Scanning – Week 2

This repository contains my Week 2 practical tasks completed during my cybersecurity internship at Networkwalks. It covers domain footprinting using Kali Linux tools, Google Hacking Database (GHDB), and local network scanning using Zenmap.

Objectives
Perform basic footprinting on the networkwalks.com domain.
Gather publicly available domain and DNS information.
Identify website technologies and security mechanisms.
Explore webcam-related information using GHDB.
Discover live hosts on my own local network using Zenmap.
Understand basic security risks and preventive measures.

Key Findings
Website technologies identified using WhatWeb.
Domain IP address discovered using nslookup.
HTTP headers examined using curl.
ModSecurity identified using WAFW00F.
DNS infrastructure information collected using DNSRecon.
Four live hosts discovered in the example local network.
Webcam-related public information explored using GHDB.
Recommendations
Keep website software and plugins updated.
Protect unnecessary server information.
Configure proper HTTP security headers.
Maintain and update WAF protection.
Review DNS records regularly.
Monitor connected network devices.
Secure webcam devices with strong passwords and authentication.
